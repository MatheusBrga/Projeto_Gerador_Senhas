Este programa utiliza a biblioteca Tkinter para criar uma interface gráfica simples que gera senhas aleatórias.

Interface: A janela principal possui tamanho fixo (400x220), fundo cinza claro e um botão centralizado chamado "Gerar Senha".
Geração de Senha: Ao clicar no botão, uma senha de 8 caracteres (com letras maiúsculas, minúsculas, números e símbolos) é criada usando o módulo random.
Exibição: A senha gerada é mostrada em uma mensagem pop-up e no console.
É uma ferramenta prática para criar senhas seguras rapidamente.
